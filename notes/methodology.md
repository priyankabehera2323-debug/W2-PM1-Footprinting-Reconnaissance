# Methodology

1. Confirmed the target domain specified in the assignment.
2. Used WHOIS to collect domain registration information.
3. Used WhatWeb to identify publicly exposed web technologies.
4. Used NSLookup to resolve the domain name.
5. Used cURL to inspect HTTPS response headers.
6. Used WAFW00F to identify a possible Web Application Firewall.
7. Used DNSRecon to enumerate publicly available DNS records.
8. Saved command outputs in the `outputs` directory.
9. Captured terminal screenshots for evidence.
10. No exploitation, brute force, vulnerability scanning, or intrusive testing was performed.
